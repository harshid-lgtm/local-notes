# Import, open & export

Bring documents into Local Notes from Word, PDF, Excel and more, and send pages out as PDF, Word, a web page or plain text.

## Import files

Click **Import** in the sidebar (or press `Ctrl O`, `⌘ O` on a Mac) and choose **Files from this computer or a drive**. You can pick several files at once, from any folder, USB stick, network drive or synced cloud folder (OneDrive, Google Drive, Dropbox, iCloud). You can also **drag files onto the window**.

Each file becomes a new page next to the page you have open. Pictures inside documents are saved in the vault's `attachments` folder.

| File | What you get |
| --- | --- |
| Word (`.docx`) | Headings, bold/italic/underline, lists, tables, links and pictures |
| PDF (`.pdf`) | The text, with headings detected from larger type. Scanned PDFs (pictures of text) have no text to import |
| Excel (`.xlsx`) | Each sheet as a table, under the sheet's name |
| CSV / TSV | A table |
| PowerPoint (`.pptx`) | One heading per slide with its text as bullet points |
| Web page (`.html`) | The article's content, without menus and footers |
| OpenDocument text (`.odt`) | Headings, paragraphs, lists and tables |
| Rich Text (`.rtf`) | The text |
| Markdown, plain text, JSON | As they are (JSON as a code block) |
| Images (`.png`, `.jpg`, `.gif`, `.webp`, `.svg`) | A page showing the picture |

Older formats (`.doc`, `.xls`, `.ppt`) need saving in the newer format first: open them in Word, Excel or PowerPoint and choose **Save As** → `.docx`, `.xlsx` or `.pptx`.

Opening a markdown file that's already inside your vault simply opens that page. To work with a whole folder of markdown files (for example on a network drive or server share), open it as a vault: vault menu → **Open another folder**.

## Import from a web address

**Import** → **From a web address**, then paste a link. It works for web pages and for links to Word, PDF, Excel and other files on a website or a server. Web pages keep their links. (Desktop app and browser mode; not in team workspaces opened in a web browser.)

## In team workspaces

Use a workspace's `•••` menu → **Import files**, or a page's `•••` menu → **Import files as subpages**. You can also drop files onto the window. Pictures are stored inside the page (up to 2 MB each).

## Export a page

Open the page's `•••` menu → **Export**:

| Format | Good for |
| --- | --- |
| **PDF** | Sharing or printing a finished page. The desktop app saves it directly; in a browser, choose **Save as PDF** in the print window |
| **Word document (.docx)** | Editing further in Word or Google Docs: headings, lists, tables, colours, links and pictures carry over |
| **Web page (.html)** | One self-contained file with pictures included, which opens in any browser |
| **Markdown (.md)** | The page exactly as stored, for other markdown apps |
| **Plain text (.txt)** | Pasting into emails or systems that don't take formatting |

**Print** is in the same menu.
